# Đối chiếu — Plugin: ai thực hiện công việc của phase?

Compiler plugin là công cụ build; PostgreSQL driver là code app dùng ở runtime. Cùng được phân phối bằng artifact không có nghĩa cùng nhiệm vụ. Packaging jar cung cấp binding compiler goal vào compile phase; POM pin compiler version và release17. Dependency không cấu hình compiler.

Dùng output và nội dung artifact làm bằng chứng; không chỉ kết luận BUILD SUCCESS. Mở solution sau khi đã ghi dự đoán và tự thử.
