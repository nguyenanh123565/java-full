# Demo — một artifact Java nhỏ

Đọc [project](project/README.md), [POM](project/pom.xml), [Main](project/src/main/java/learning/Main.java). Trước command `mvn compile`, ghi file nào bạn nghĩ sẽ có trong target và liệu main có chạy chưa.

Project không có application dependency. Maven dùng compiler plugin được chốt phiên bản và release 17. Chỉ chạy khi muốn thực hành; không có script cài đặt tự động.
