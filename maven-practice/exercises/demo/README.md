# Điểm xuất phát cho bài tổng hợp

Đọc [project Java17](../../01-why-build-tool/demo/project/README.md), [POM](../../01-why-build-tool/demo/project/pom.xml) và [source](../../01-why-build-tool/demo/project/src/main/java/learning/Main.java). Nếu muốn sửa, tạo bản copy riêng; không cần download để đọc cấu trúc.

Demo minh họa compile/resource/package và smoke check manual. [Bài tổng hợp](../README.md) yêu cầu hàm/label mới và bảng dự đoán phase; [notes](../notes.md) ghi bằng chứng kiểm tra. Maven test phase không tự chạy smoke main chỉ vì nó nằm dưới src/test/java.
