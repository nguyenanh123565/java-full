# Đối chiếu — POM: mô tả project và tọa độ artifact

Artifact mặc định sẽ là product-total-1.1.0.jar; resource app.properties vẫn giữ đường dẫn của nó. modelVersion là phiên bản cấu trúc POM, không phải Maven executable. Release17 tạo bytecode/API mục tiêu17; JVM mới hơn tương thích có thể chạy, không bắt buộc chỉ JDK17.

Dùng output và nội dung artifact làm bằng chứng; không chỉ kết luận BUILD SUCCESS. Mở solution sau khi đã ghi dự đoán và tự thử.
