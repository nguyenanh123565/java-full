# Khảo sát trước khi bổ sung bài tập — 22/10/2026

Phạm vi là `java-core-practice` có thật tại workspace hiện tại. Không có AGENTS.md ở thư mục gốc/cha liên quan hoặc trong Java Core. Đã đọc hướng dẫn README/STRUCTURE/VALIDATION của workspace, README/POM/build.ps1 của Java Core và khảo sát README, Demo, Exercise, Solution cùng skeleton của các mục. Không có file tutorial riêng; README hiện chứa phần giải thích.

Trước bổ sung có **58 mục học**: **51 mục có source** (159 file Java, gồm model/service skeleton) và **7 mục nhóm**. Mỗi mục source đã có ba bài cũ, Demo và Solution riêng; bảy mục nhóm có ba hướng ôn chung, chưa có bộ tự kiểm tra riêng. Ba mini project có cả Solution dạng TODO. Bộ mới dẫn lại bài cũ và thêm tình huống, trace/tìm lỗi, biến thể hoặc tổng kết; không điền đè TODO của người học.

Đã nhận diện ghi chú/bài làm thật trong README variables, strings và code hiện có. Lưu SHA-256 và độ dài của 1056 file workspace trước khi sửa vào target; kiểm lại bytes gốc, cho phép README chỉ nối thêm phần liên kết. Giữ nguyên cả file .class cũ ngoài target. Workspace không có Git repository ở cấp gốc nên không dựa vào git diff để chứng minh bảo toàn.

Quy ước mới tại mỗi mục là `exercises/{README.md,hints.md,review.md,starter/Starter.java,solutions/README.md,solutions/ReferenceSolution.java}`. Đề luôn tách khỏi gợi ý/lời giải; package starter/solutions riêng nên không xung đột source gốc. Mục nhóm là tổng kết sau các mục con.

Tiên quyết tóm tắt ở bảng dưới; hợp đồng và giới hạn cụ thể nằm ở đầu từng đề. Các ví dụ cũ dùng khái niệm chặng sau vẫn được giữ nguyên, bộ mới chỉ yêu cầu kiến thức đúng chặng. Không sửa HTTP/REST, SQL/PostgreSQL hoặc khu học khác.
