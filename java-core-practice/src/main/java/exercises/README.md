# Luyện tổng hợp

## Dùng để làm gì?
Tự giải thuật toán trước khi ghép vào chương trình có nhiều object.

## Thứ tự học
1. [easy](easy/README.md)
2. [medium](medium/README.md)
3. [mini_projects](mini_projects/README.md)

## Những ý bắt buộc phải hiểu
- Viết quy ước input/output và trường hợp biên trước code.
- Giải thích tính đúng đắn và độ phức tạp.
- Làm trên file Exercise; Solution để riêng.

## Lỗi người mới thường gặp
- Chỉ thử một input đẹp.
- Copy lời giải trước khi hiểu vì sao đúng.

## Câu hỏi tự kiểm tra
1. Thuật toán có sửa input không?
2. Input rỗng nên có kết quả gì?
3. Có thể giải thích invariant trước khi chạy không?

## Ba bài tập từ dễ đến khó
1. Dễ: làm 10 bài easy từ duyệt mảng đến Binary Search.
2. Vừa: hoàn thành ba bài medium.
3. Khó: tự triển khai một mini project với validation và menu.


## Bộ tự kiểm tra cuối mục

Làm [bài tập mở rộng](exercises/README.md), rồi hoàn tất [checklist và câu hỏi tự luận](exercises/review.md). Gợi ý và lời giải nằm riêng; phần nội dung/bài làm phía trên được giữ nguyên.
