## Những ý bắt buộc phải hiểu
- Mỗi bài có package và Demo/Exercise/Solution/README riêng.
- Input không null; mỗi README quy định hành vi với dữ liệu rỗng.
- Nêu O(n), O(log n), O(k) và vì sao.

## Lỗi người mới thường gặp
- Quên số âm, phần tử trùng hoặc rỗng.
- Sửa input ngoài ý muốn hoặc cộng int bị tràn.

## Câu hỏi tự kiểm tra
1. Khi nào hai con trỏ hợp lý?
2. HashMap giúp giảm vòng lặp lồng nhau như thế nào?
3. Vì sao Binary Search cần mảng sorted?

## Ba bài tập từ dễ đến khó
1. Dễ: Find Max, Find Min, Reverse Array và Palindrome.
2. Vừa: Count Frequency, Remove Duplicate và Character Frequency.
3. Khó: Two Sum, Valid Parentheses và Binary Search; giải thích invariant.
