# Tự đánh giá

- [ ] PAL-01: đã tự làm, chạy dữ liệu mẫu/biên và giải thích lý do.
- [ ] PAL-02: đã tự làm, chạy dữ liệu mẫu/biên và giải thích lý do.
- [ ] PAL-03: đã tự làm, chạy dữ liệu mẫu/biên và giải thích lý do.
- [ ] PAL-04: đã tự làm, chạy dữ liệu mẫu/biên và giải thích lý do.
- [ ] Đã lưu dự đoán trước khi chạy và nguyên nhân nếu dự đoán sai.
- [ ] Đã kiểm việc sửa dữ liệu nguồn, thứ tự, dữ liệu rỗng và lỗi theo hợp đồng.
- [ ] Đã giải thích thời gian/bộ nhớ của phần viết code bằng kích thước đầu vào.

## Câu hỏi tự luận

1. Bất biến nào chứng minh kết quả khi vòng lặp dừng?
2. Biến thể mới khác hợp đồng bài cũ ở điểm nào?
3. Ca biên nào phân biệt một bản sửa đúng với bản sửa chỉ đúng ví dụ?
