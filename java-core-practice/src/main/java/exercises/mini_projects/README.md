# Ba mini project — chỉ skeleton

## Dùng để làm gì?
Tự kết hợp model, service, collection, exception và menu console.

## Thứ tự học
1. [student_management](student_management/README.md)
2. [product_management](product_management/README.md)
3. [banking_simulation](banking_simulation/README.md)

## Những ý bắt buộc phải hiểu
- Không có lời giải nghiệp vụ sẵn; cả file Solution chỉ có gợi ý TODO.
- Dữ liệu chỉ trong bộ nhớ, không framework hay database.
- Dùng long theo số đồng nguyên cho tiền; validate trước mutation.

## Lỗi người mới thường gặp
- Nhét toàn bộ nghiệp vụ vào console.
- Cập nhật dữ liệu trước khi kiểm tra tất cả điều kiện.

## Câu hỏi tự kiểm tra
1. Model phải giữ bất biến nào?
2. Service cần chịu trách nhiệm gì?
3. Làm sao chứng minh lỗi không đổi trạng thái?

## Ba bài tập từ dễ đến khó
1. Dễ: Student Management — CRUD và thống kê điểm.
2. Vừa: Product Management — tồn kho và sắp xếp giá.
3. Khó: Banking Simulation — nạp/rút/chuyển với kiểm tra trước cập nhật.
