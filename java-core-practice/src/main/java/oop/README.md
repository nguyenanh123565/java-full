## Những ý bắt buộc phải hiểu
- Phân biệt class, object và reference.
- Encapsulation bảo vệ bất biến; interface mô tả hợp đồng.
- Overload chọn lúc biên dịch; override instance method dispatch lúc chạy.

## Lỗi người mới thường gặp
- Coi mọi quan hệ là kế thừa.
- Nhầm kiểu reference với lớp thật của object.

## Câu hỏi tự kiểm tra
1. Constructor có được kế thừa không?
2. Vì sao interface reference có thể gọi implementation khác nhau?
3. Khi nào dùng composition?
