## Phần bổ sung bài tập tự kiểm tra

Cây phía trên mô tả các file có trước đợt bổ sung. Mỗi mục trong
[bảng tiến độ](PROGRESS.md), kể cả mục nhóm, nay có thêm cấu trúc:

```text
exercises/
├── README.md
├── starter/Starter.java
├── hints.md
├── review.md
└── solutions/
    ├── README.md
    └── ReferenceSolution.java
```

Các file gốc vẫn giữ nguyên; danh sách đầy đủ các mục nằm trong
[khảo sát](PRACTICE_AUDIT.md). Cấp gốc thêm STUDY_GUIDE.md, PROGRESS.md,
PRACTICE_AUDIT.md, PRACTICE_VALIDATION.md và verify-exercises.ps1.
