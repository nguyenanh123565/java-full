# Tiến độ bài tập Java Core mới

Trạng thái chỉ áp dụng cho bộ bài mới, không suy đoán tiến độ bài làm/ghi chú cũ của bạn. Chọn đúng một trạng thái mỗi mục; dùng cột ghi chú để ghi mã bài đang làm hoặc thêm dòng riêng theo mã nếu muốn theo dõi từng bài.

- **Chưa làm:** chưa bắt đầu bộ bài.
- **Đang làm:** đã thử, còn bài/ca sai hoặc còn cần gợi ý.
- **Đã chạy đúng:** đã tự chạy ví dụ, biên và lỗi theo đề; biên dịch đơn thuần chưa đủ.
- **Đã giải thích được:** đã trả lời review và giải thích cách làm/lỗi/giới hạn bằng lời của mình.
