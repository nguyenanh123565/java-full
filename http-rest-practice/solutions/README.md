# Đáp án tham khảo riêng

Các file `01-...md` đến `14-...md` tương ứng với ba bài trong từng chủ đề.
`exercises/` có đáp án chọn lọc/gợi ý cho các bộ luyện tập.
`mini-api-designs/` chỉ có tiêu chí và gợi ý để tự đánh giá, không điền toàn bộ ma trận endpoint.

Tự làm trước, ghi lý do, thử ca lỗi rồi mới mở đáp án. Có thể có nhiều contract hợp lý;
quan trọng là semantics, tính nhất quán và quy tắc nghiệp vụ được giải thích rõ.
Không tự động chép đáp án vào `exercises.md` hoặc `requests.http`.

Server lab chỉ giúp quan sát HTTP. Các đáp án thiết kế users/products/orders không phải
những route đã được server lab hiện thực. Đọc README lab để biết phần chạy được.
