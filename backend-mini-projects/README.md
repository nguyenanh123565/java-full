# Backend mini projects — ghép từng chặng

Mỗi project chỉ thêm một nhóm cơ chế mới. Tái sử dụng kiến thức, không sửa file
ở workspace cũ: tạo bài làm của mình trong `exercise/` của project tương ứng.
Project 01 và 03 có demo Java chạy bằng JDK; 02/04 dẫn về lab chuyên môn để
tránh nhân bản cùng một codebase; project cuối là đề tổng hợp, không phải app đã giải sẵn.

| Thứ tự | Project | Điều kiện |
| --- | --- | --- |
| 01 | [Java CLI Product Management](01-java-cli-product-management/README.md) | Java Core: class, method, collection, exception; Git commit |
| 02 | [Java + JDBC Product Management](02-java-jdbc-product-management/README.md) | Project 01 + SQL + JDBC CRUD/transaction |
| 03 | [Simple HTTP API bằng Java thuần](03-simple-http-api/README.md) | Project 01 + HTTP method/URL/status/JSON |
| 04 | [Spring Boot Product API](04-spring-boot-product-api/README.md) | JDBC + Maven + Spring MVC/DI/DTO/validation/error |
| 05 | [E-commerce Backend monolith nhỏ](05-ecommerce-backend/README.md) | Project 04 + JPA + Security + Testing + Docker/Linux cơ bản |

Mỗi project có demo, exercise TODO, solution đối chiếu riêng và notes. Chỉ mở
solution sau khi có lần thử đầu tiên. Dự đoán output/response/SQL trước khi chạy.
Làm [checklist chung](project-checklists/README.md) và ghi bằng chứng, không chỉ tick.
