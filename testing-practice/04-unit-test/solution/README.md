# Đối chiếu sau khi tự làm — Unit test và fake viết tay

Fake mới cho từng test tránh rò trạng thái. Unit test kiểm quyết định service; cần integration test để kiểm query và mapping thật.

Kiểm lại dự đoán với demo. Một lời giải đạt yêu cầu phải nêu input cụ thể,
expected độc lập và ranh giới test. Không chỉ viết “test pass”.
