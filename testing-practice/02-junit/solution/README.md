# Đối chiếu sau khi tự làm — JUnit và Arrange / Act / Assert

Mỗi test một tình huống, Arrange dữ liệu mới. @Test chỉ đánh dấu; assertEquals mới đối chiếu hành vi.

Kiểm lại dự đoán với demo. Một lời giải đạt yêu cầu phải nêu input cụ thể,
expected độc lập và ranh giới test. Không chỉ viết “test pass”.
