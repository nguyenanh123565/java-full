# Đối chiếu sau khi tự làm — Assertion diễn đạt hợp đồng

Dùng assertEquals cho value hợp đồng, assertThrows cho lỗi. Với tiền cùng giá trị khác scale, compareTo == 0 nếu hợp đồng không bắt buộc scale.

Kiểm lại dự đoán với demo. Một lời giải đạt yêu cầu phải nêu input cụ thể,
expected độc lập và ranh giới test. Không chỉ viết “test pass”.
