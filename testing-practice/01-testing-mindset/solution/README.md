# Đối chiếu sau khi tự làm — Test để bắt sai hành vi

Chọn expected từ yêu cầu nghiệp vụ, không chép biểu thức đang kiểm. Giá/số lượng sai phải bị từ chối trước phép nhân.

Kiểm lại dự đoán với demo. Một lời giải đạt yêu cầu phải nêu input cụ thể,
expected độc lập và ranh giới test. Không chỉ viết “test pass”.
