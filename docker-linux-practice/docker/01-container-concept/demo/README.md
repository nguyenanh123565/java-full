# Demo — đọc cấu trúc trước khi chạy

Đọc [Compose demo](../../java-postgresql-demo/README.md) và [compose.yaml](../../java-postgresql-demo/compose.yaml). Chỉ có app và db, không thêm message broker/orchestrator.

Nếu bạn đã chủ động chạy demo, tại thư mục chứa compose.yaml dùng `docker compose ps` và `docker compose logs --tail 20 app`. Đánh dấu image/container/process/volume/network trên sơ đồ riêng. Không khởi động container chỉ để hoàn thành bài đọc.
