# Đối chiếu — Linux filesystem: đường dẫn và working directory

Sau cd vào data/, item.txt nằm ngay cwd còn data/item.txt tìm thư mục data lồng bên trong. File system path được OS giải; URL route do HTTP server giải; table name do PostgreSQL giải. Classpath resource dùng classloader nên không cần đường dẫn source còn tồn tại.

Đối chiếu với output thật; nếu chưa chạy môi trường tương ứng, ghi rõ đây là dự đoán chứ chưa phải kết quả kiểm tra.
