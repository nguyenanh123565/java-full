# Đối chiếu — Environment variable: cấu hình của process

Environment được truyền lúc tạo process; cần tạo lại process để nhận env mới. SQL parameter là dữ liệu của câu SQL; HTTP query parameter đi cùng request; DB URL là cấu hình kết nối. `.env` chỉ là file và cần công cụ cụ thể đọc nó; Java getenv không tự parse file đó.

Đối chiếu với output thật; nếu chưa chạy môi trường tương ứng, ghi rõ đây là dự đoán chứ chưa phải kết quả kiểm tra.
