# Đối chiếu sau khi tự làm — Branch: tên trỏ vào một dòng lịch sử

Ngay sau tạo branch, hai tên cùng trỏ commit cũ; commit feature chỉ cập nhật ref feature. Main không chứa file mới cho đến khi merge. Git quản lý file SQL chứ không tự chạy migration lên database.

So với dự đoán của bạn: điều nào đúng, điều nào sai, và bằng chứng nào làm bạn đổi cách hiểu? Một câu trả lời dùng thuật ngữ nhưng không giải thích được ví dụ chưa đủ.
