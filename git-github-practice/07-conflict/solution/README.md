# Đối chiếu sau khi tự làm — Conflict: Git cần quyết định từ con người

Trong sandbox, sửa product.txt thành nội dung hợp lệ chứa giá 140, kiểm tra `git diff`, `git add product.txt`, `git commit -m "Resolve final product price"`, rồi xem `git log --graph --oneline`. 140 đến từ quyết định nghiệp vụ; Git chỉ cung cấp lịch sử để hỗ trợ quyết định. Không để marker trong kết quả.

So với dự đoán của bạn: điều nào đúng, điều nào sai, và bằng chứng nào làm bạn đổi cách hiểu? Một câu trả lời dùng thuật ngữ nhưng không giải thích được ví dụ chưa đủ.
