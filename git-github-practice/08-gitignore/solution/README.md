# Đối chiếu sau khi tự làm — .gitignore: bỏ qua file sinh ra và cấu hình riêng

Chỉ file untracked khớp pattern bị bỏ qua. Source, pom.xml, migration và request mẫu không chứa token nên được version control; output build, log và .env riêng nên bỏ qua. Bí mật đã lộ phải được thu hồi/thay mới; .gitignore không làm người khác quên lịch sử.

So với dự đoán của bạn: điều nào đúng, điều nào sai, và bằng chứng nào làm bạn đổi cách hiểu? Một câu trả lời dùng thuật ngữ nhưng không giải thích được ví dụ chưa đủ.
