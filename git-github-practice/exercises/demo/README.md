# Điểm xuất phát cho bài tổng hợp

Chọn [demo staging](../../02-working-tree-staging-commit/demo/demo.ps1), [merge](../../04-merge/demo/demo.ps1) và [hai clone](../../06-pull-push/demo/demo.ps1) để quan sát cơ chế độc lập trước khi tự ghép bài tổng hợp. Mỗi script tự tạo sandbox tạm; không có dữ liệu thật và không liên hệ mạng.

Đừng chép toàn bộ script thành đáp án. Bài tổng hợp yêu cầu tự tạo graph và contract mới, viết dự đoán, giải thích vì sao rồi kiểm tra Java/HTTP/SQL. [Bài cần làm](../README.md); [notes của bài tổng hợp](../notes.md).
