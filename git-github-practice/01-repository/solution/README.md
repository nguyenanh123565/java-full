# Đối chiếu sau khi tự làm — Repository: source code và lịch sử

File mới là untracked; sau add nằm trong staging; sau commit sạch; sau sửa là tracked modified. `.git` mới chứa lịch sử. Chạy Java chỉ cần code/classpath phù hợp, không cần metadata Git.

So với dự đoán của bạn: điều nào đúng, điều nào sai, và bằng chứng nào làm bạn đổi cách hiểu? Một câu trả lời dùng thuật ngữ nhưng không giải thích được ví dụ chưa đủ.
