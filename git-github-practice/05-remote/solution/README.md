# Đối chiếu sau khi tự làm — Remote và origin: địa chỉ chia sẻ lịch sử

`remote add` chỉ cập nhật cấu hình local. Commit vẫn chỉ nằm local cho đến khi push. Remote Git chứa source/migration đã commit, không chứa row trong DB hoặc environment variable chỉ có ở runtime.

So với dự đoán của bạn: điều nào đúng, điều nào sai, và bằng chứng nào làm bạn đổi cách hiểu? Một câu trả lời dùng thuật ngữ nhưng không giải thích được ví dụ chưa đủ.
