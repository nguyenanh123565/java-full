# Đối chiếu sau khi tự làm — Fetch, pull, push: trao đổi commit

Chỉ commit được truyền. Fetch cập nhật origin/main; working tree chỉ đổi khi tích hợp. Push non-fast-forward bị từ chối vì cập nhật trực tiếp có thể làm mất đường dẫn đến commit phía remote. Đọc graph, tích hợp có chủ ý, kiểm tra rồi push lại.

So với dự đoán của bạn: điều nào đúng, điều nào sai, và bằng chứng nào làm bạn đổi cách hiểu? Một câu trả lời dùng thuật ngữ nhưng không giải thích được ví dụ chưa đủ.
