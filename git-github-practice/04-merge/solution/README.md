# Đối chiếu sau khi tự làm — Merge: kết hợp hai dòng thay đổi

Khi hai nhánh đã có commit riêng, main không phải tổ tiên trực tiếp của feature nên cần tích hợp; merge commit thường có hai cha. Git kết hợp văn bản, không chứng minh Java compile hoặc quy tắc SQL còn đúng.

So với dự đoán của bạn: điều nào đúng, điều nào sai, và bằng chứng nào làm bạn đổi cách hiểu? Một câu trả lời dùng thuật ngữ nhưng không giải thích được ví dụ chưa đủ.
