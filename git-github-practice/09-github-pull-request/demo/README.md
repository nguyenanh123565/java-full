# Demo review PR bằng repository sandbox

1. Đọc log và `git diff main...feature/search` trong repo thử đã có hai branch.
2. Viết “Problem”: chưa lọc product theo tên; “Behavior”: thêm query parameter tùy chọn.
3. Viết kiểm tra: không truyền name / có kết quả / không có kết quả / tên chứa khoảng trắng.
4. Kiểm tra diff không chứa target/, .env hay sửa bài ngoài phạm vi.
5. Khi thực sự dùng GitHub sau này: chọn đúng base/head, tạo draft PR rồi tự review trước khi đề nghị người khác xem.

Không cần tài khoản hoặc thao tác mạng để hoàn thành bài học này.
