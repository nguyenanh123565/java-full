# Đối chiếu sau khi tự làm — Pull Request: đề nghị review một thay đổi

Một bản nháp tốt nêu trigger, hành vi trước/sau, ví dụ GET /products?name=Book trả 200 cùng danh sách phù hợp, cách kiểm tra và giới hạn. Base là nơi nhận thay đổi, head là nơi chứa thay đổi. PR thuộc nền tảng cộng tác; `git pull` là lệnh nhận và tích hợp commit.

So với dự đoán của bạn: điều nào đúng, điều nào sai, và bằng chứng nào làm bạn đổi cách hiểu? Một câu trả lời dùng thuật ngữ nhưng không giải thích được ví dụ chưa đủ.
