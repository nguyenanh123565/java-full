# Đối chiếu sau khi tự làm — CRUD bằng JDBC

Chu trình demo tạo một hàng riêng, lấy id bằng RETURNING, update count 1, delete count 1 rồi không tìm thấy nữa. Identity sequence có thể có khoảng trống; không suy ra số hàng từ id.

Hãy dùng dữ liệu khác demo để kiểm tra lại. Một kết quả chạy đúng nhưng không giải thích được luồng vẫn chưa đủ. Đối chiếu với README workspace để giữ đúng phạm vi công nghệ.
