# Đối chiếu sau khi tự làm — JDBC overview

Giá trị được in là 1. SQL thực thi tại PostgreSQL; ResultSet chỉ là cách JDBC duyệt dữ liệu. Record Product được tạo bởi code mapper của bạn, không phải database gửi một Java object.

Hãy dùng dữ liệu khác demo để kiểm tra lại. Một kết quả chạy đúng nhưng không giải thích được luồng vẫn chưa đủ. Đối chiếu với README workspace để giữ đúng phạm vi công nghệ.
