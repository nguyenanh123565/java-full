# Đối chiếu sau khi tự làm — Statement và SQL cố định

Statement dùng được cho SQL cố định như SELECT current_database(). Khi input được ghép vào SQL, database phân tích nó như một phần cú pháp; đó là điểm cần sửa bằng parameter binding.

Hãy dùng dữ liệu khác demo để kiểm tra lại. Một kết quả chạy đúng nhưng không giải thích được luồng vẫn chưa đủ. Đối chiếu với README workspace để giữ đúng phạm vi công nghệ.
