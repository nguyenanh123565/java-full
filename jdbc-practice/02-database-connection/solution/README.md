# Đối chiếu sau khi tự làm — Connection và DriverManager

javac chỉ cần interface java.sql của JDK. Driver jar cần lúc chạy. Thiếu biến phải dừng với thông báo rõ; lỗi kết nối có thể xem SQLState nhưng không ghi mật khẩu/JDBC URL chứa secret.

Hãy dùng dữ liệu khác demo để kiểm tra lại. Một kết quả chạy đúng nhưng không giải thích được luồng vẫn chưa đủ. Đối chiếu với README workspace để giữ đúng phạm vi công nghệ.
